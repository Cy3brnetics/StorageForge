# Audit 2026-10-29 - gemini

## Executive Summary

This full-stack security, logic, and infrastructure audit inspected every Python module (`26` files in `storageforge_index/`), every frontend module (`8` JS files + `2` HTML files in `static/`), all `15` SQLite and `15` PostgreSQL schema migrations, all **85 HTTP routes** in `server.py`, all `23` CLI subcommands in `cli.py`, and the complete Docker/Nginx/demo stack (`Dockerfile`, `docker-compose.yml`, `docker/*`, `examples/demo/*`, `secrets/`).

Prior audits (`security-audit-2026-10-28.md` `SF-01..SF-27`, `docs/audit-2026-10-29.md`, and `notebook/Audit 2026-10-29 - features.md` `PF-01..PF-17` / `EQ-01..EQ-03`) addressed many foundational issues. Rather than duplicating those items, this audit focuses on **25 newly uncovered vulnerabilities, broken code paths, database crashes, and container bugs (`GM-01` through `GM-25`)**:

- **1 Critical**: [[GM-01 Restore unpack as root allows device nodes and TOCTOU|GM-01]] (Root `tar -C "$t" -xpf -` during snapshot restore extracts arbitrary block/char device nodes via `mknod` and leaves a multi-hour TOCTOU window before `find` strips setuid bits).
- **15 High**: Remote command injection in `scriptkit.py:REMOTE` `--host` relay ([[GM-02 Remote command injection in scriptkit host relay|GM-02]]), `203/EXEC` failure of all systemd-deployed storage tasks due to `RUNNER_UPDATE` lacking `#!` ([[GM-03 Deployed tasks fail under systemd with 203 EXEC due to missing shebang|GM-03]]), `StrictHostKeyChecking=accept-new` running *before* `hostkeys.require_confirmed` in `/api/keys/install` ([[GM-04 Key install probes host with accept-new before host key confirmation|GM-04]]), arbitrary wildcard vault binding in `/api/deploy/adopt` ([[GM-05 Deploy adopt lacks hostname validation and binds arbitrary vault patterns|GM-05]]), alert bearer token leakage on `https -> http` scheme downgrade/port change + SSRF via DNS rebinding ([[GM-06 Alert settings leak secret tokens on URL change and allow SSRF via IPv4-mapped IPv6 and DNS rebinding|GM-06]]), unvalidated `tier`/`kind` fields + unescaped `innerHTML` sinks in `planner.js` ([[GM-07 Planner scrub is a no-op and innerHTML sinks lack escaping|GM-07]]), leading-hyphen `rsync`/`ssh` option injection in `tasks.py` and `remote.py` ([[GM-08 Leading-hyphen hostnames allow rsync and ssh option injection in tasks and remote|GM-08]]), recursive group clobbering + ignored recursive `chmod` + symlink traversal in `changes.py` ([[GM-09 Change plan perms task clobbers descendant groups and follows symlinks as root|GM-09]]), 4 broken backup/snapshot code paths in `jobscript.py` ([[GM-10 Four broken code paths in jobscript backup and snapshot execution|GM-10]]), missing `@password_confirmed` on remote-execution and security-critical endpoints ([[GM-11 Missing password confirmation on remote execution and security-critical routes|GM-11]]), Waitress 8-thread pool starvation via 6-hour synchronous restore/job endpoints ([[GM-12 Waitress 8-thread pool exhaustion via synchronous 6-hour restore and deploy endpoints|GM-12]]), 5 PostgreSQL runtime crashes ([[GM-13 PostgreSQL runtime crashes across folders, backups, alerts, shares, and timestamps|GM-13]]), child Btrfs subvolumes skipped by both `'alias'` and `-prune` in `scanner.py` ([[GM-14 Scanner skips child Btrfs subvolumes by marking them alias while also pruning them|GM-14]]), silent failure of Docker `./keys` import + empty `scan` password in `Dockerfile.target` ([[GM-15 Docker keys import fails silently on 0700 permissions and demo target has empty scan password|GM-15]]), and `entrypoint.sh` pre-`restore` corruption / global flag bypasses ([[GM-16 Entrypoint bypasses on global flags and destructive pre-restore initialization|GM-16]]).
- **8 Medium & 1 Low**: Proxy header spoofing ([[GM-17 Proxy header spoofing on shared Docker networks and broken multi-hop X-Forwarded-For|GM-17]]), egress firewall fail-open crash & `INPUT` bypass ([[GM-18 Egress firewall fails open on bridge switch or invalid port and misses host INPUT chain|GM-18]]), global 24h account lockout & `audit_log` DoS ([[GM-19 Global account lockout DoS and unauthenticated audit_log flooding on login|GM-19]]), `deploy.enroll` / `sudo_run` failures without scan binding or on non-22 ports ([[GM-20 Deploy enroll and sudo_run fail without existing scan key binding or on non-default SSH ports|GM-20]]), `moves.py` `verify_step` ignoring `rsync` failures & `shares.py` false drift alerts ([[GM-21 Move plan verify_step ignores rsync exit code and shares fstab preservation triggers false drift|GM-21]]), restore dropping `pack` errors & leaving empty directories ([[GM-22 Cross-host restore drops pack error output, lacks runner lock, and leaves empty directories|GM-22]]), inventory parser / capacity / `run_dupes` bugs ([[GM-23 Inventory section parser collisions, missing mountinfo superblock options, and capacity edge cases|GM-23]]), 825-day TLS cert rejection & skipped root tests in `Dockerfile` ([[GM-24 TLS 825-day cert rejected by modern browsers, nginx IPv6 and cipher gaps, and skipped tests in Dockerfile|GM-24]]), and thread-safety / cache / SQLite nested transaction races ([[GM-25 Thread-safety races in folder_cache, backup.create, Vault._UNLOCKED, and SQLite nested tx|GM-25]]).
